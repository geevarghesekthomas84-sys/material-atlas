# Material Atlas v1.1.0

This release expands the selected Google Material Symbols collection to **258 names and 774 SVG variants**. The explorer now uses Google category and search tag metadata, so searches such as `hamburger` can find `menu`.

It also adds a portable AI skill and three read-only MCP tools for searching icons, inspecting styles and attribution, and retrieving exact published SVGs. Use the attached plugin ZIP with a compatible desktop plugin installer, or follow [AI integration setup](https://github.com/geevarghesekthomas84-sys/material-atlas/blob/main/docs/ai-integrations.md) for Codex, Claude Code, Gemini CLI, and GitHub Copilot CLI. The repository includes source for a hosted MCP endpoint for ChatGPT and Codex.

The gallery and AI catalog cover **1,824 collection entries (1,617 distinct names) and 7,654 SVG variants** across Google's classic Material Icons, selected Material Symbols, and independent Atlas additions. Material Atlas is independent and is not endorsed by Google. Preserve the included Apache 2.0 license and source notices when redistributing assets.
