# Material Atlas v1.0.0

The first public release of [Material Atlas](https://geevarghesekthomas84-sys.github.io/material-atlas/), an icon explorer with search, style comparison, color previews, saved icons, shareable links, and custom ZIP packs.

The website includes 6,862 classic Material Icons SVG variants, 138 selected Material Symbols SVG variants, and 18 independent original SVGs. See the [project README](https://github.com/geevarghesekthomas84-sys/material-atlas#readme) for setup and attribution.

## Download classic platform assets

- **Android:** `material-icons-android.zip` — classic Android drawable and PNG assets.
- **iOS:** `material-icons-ios.zip` — classic iOS image assets and metadata.
- **PNG:** `material-icons-png.zip` — classic pre-rendered PNG assets.
- **Checksums:** `SHA256SUMS.txt` — SHA-256 hashes for the three ZIPs.

These three archives are from the **legacy Google Material Icons 4.0.0** collection. They do not include newer Material Symbols or the independent Material Atlas originals. Every ZIP includes `LICENSE.txt` and `SOURCE-NOTES.txt`.

Material Atlas is an independent project and is not endorsed by Google. Google's artwork is provided under Apache License 2.0.
