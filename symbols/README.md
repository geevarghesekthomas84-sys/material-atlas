# Selected official Material Symbols

These SVGs are from [Google's Material Design Icons repository](https://github.com/google/material-design-icons), revision `10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7`. The 258 names were selected from [Google Fonts icon metadata](https://fonts.google.com/metadata/icons?incomplete=1&key=material_symbols) by popularity while retaining all previously included names. This is a curated selection, not the complete collection. Each icon is included in outlined, rounded, and sharp 24 px versions.

`selection.json` records names, categories, search tags, and the popularity value used for selection. Run `python symbols/select.py --popular 240` to refresh this selection from Google's metadata, then run `python symbols/sync.py` to fetch missing SVGs and regenerate `manifest.json`. Add `--refresh` to download every selected SVG again from the pinned revision. If you change the pinned revision in `sync.py`, use `--refresh` so existing files come from the new revision too. The artwork remains Google's and is covered by the repository's Apache 2.0 license.
