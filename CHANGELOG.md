# Changelog

## v1.0.0 — First public release

- Published Material Atlas, a searchable static explorer for 6,862 classic Material Icons SVG variants, 138 selected Material Symbols SVG variants, and 18 independent original SVGs.
- Added style comparison, color and size previews, variable Material Symbols font controls, saved icons, shareable links, and ZIP packs.
- Added browser and catalog checks to the GitHub validation workflow.
- Published separately labeled classic Android, iOS, and PNG asset archives with the license and source notes included in each ZIP.

The classic platform archives are from the Material Icons 4.0.0 collection. They do not contain current Material Symbols or Material Atlas originals. Material Atlas is independent and is not endorsed by Google.
