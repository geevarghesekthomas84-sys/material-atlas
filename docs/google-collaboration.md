# A practical path to collaborate with Google

Material Atlas is independent and should not be described as a Google partnership. The project can still be shared as a useful open-source tool, with clear links to Google's source artwork and license.

Google's [Material Design Icons repository](https://github.com/google/material-design-icons#icon-requests) invites **icon concepts** through GitHub issues. It says finished SVG icon submissions are not accepted as pull requests because Google maintains upstream design sources and guidelines.

For an icon request:

1. Identify a specific missing concept and the interface where it would help.
2. Check the current [Material Symbols library](https://fonts.google.com/icons) for an existing equivalent.
3. Open an issue in Google's repository with the use case and a few visual references. Explain the concept; do not submit a finished SVG as the proposed upstream asset.
4. Link to this explorer only if it helps show a real example. State that the explorer and original additions are independent.

For a broader collaboration, publish a working demo and ask the maintainers whether feedback on discovery, accessibility, or documentation would be useful. Do not promise an official relationship or imply endorsement before Google explicitly agrees.
